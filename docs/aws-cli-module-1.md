# AWS CLI Module 1

## Learning Objectives

- Understand what the AWS CLI is.
- Install the AWS CLI.
- Configure credentials.
- Learn the command structure.
- Manage AWS resources from the terminal.

---

## What is the AWS CLI?

The AWS Command Line Interface (CLI) is a tool that allows you to interact with AWS services directly from the terminal instead of using the AWS Management Console.

---

## CLI Workflow

You
↓
AWS CLI
↓
AWS Credentials
↓
AWS API
↓
AWS Service
↓
JSON Response
↓
Terminal

---

## Why Learn the AWS CLI?

- Faster than the console
- Automates repetitive tasks
- Enables scripting
- Required for Infrastructure as Code
- Used by DevOps and Cloud Engineers
